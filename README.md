# MORI Coffee

Standalone, English-language, multi-page portfolio concept. No dependencies or build step. All page links and assets are relative, suitable for GitHub Pages.

Open through a static HTTP server. Publish with GitHub Pages: main branch, / (root).

Small CSS and JavaScript interactions respect prefers-reduced-motion. Data stays in this browser. No real orders, reservations, payments or message delivery. Prices are illustrative and remain in UAH.

Photos: illustrative Unsplash photographs, loaded remotely. FORMA objects are original SVG illustrations. ORBIT case studies discuss fictional portfolio concepts, not real commissioned client work.
